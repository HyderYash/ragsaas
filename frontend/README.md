# RAG SaaS Frontend

This is the Next.js dashboard for the RAG SaaS app.

For full product documentation, setup, backend instructions, API reference, and deployment notes, see [../README.md](../README.md).

## Run

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Checks

```bash
npm run lint
npm run build
```

## Environment

Copy `.env.example` to `.env` and set Clerk/API values as needed.
